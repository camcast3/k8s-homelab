# Talos Homelab on Proxmox

Automated Kubernetes homelab using Talos Linux on Proxmox VE with multi-node HA distribution.

## Architecture

- **Platform**: Proxmox VE (2 nodes for HA)
- **OS**: Talos Linux v1.11.5
- **Orchestration**: Kubernetes
- **Network**: Static IPs via Talos configuration
- **IaC**: OpenTofu (Terraform)
- **Configuration Management**: Ansible

## Features

- ✅ Fully automated VM provisioning
- ✅ Multi-node HA distribution (2 Proxmox hosts)
- ✅ Static IP configuration via Talos
- ✅ Per-node storage and network configuration
- ✅ High-availability control plane with VIP
- ✅ Generates Ansible inventory automatically
- ✅ Complete E2E deployment script

## Quick Start

### 1. Prerequisites

Install required tools:
```bash
# OpenTofu
brew install opentofu

# Talosctl
curl -sL https://talos.dev/install | sh

# Kubectl
brew install kubectl

# Ansible
pip install ansible
```

### 2. Configure Credentials

Create `infrastructure/creds.auto.tfvars`:
```hcl
# Proxmox
proxmox_token_id     = "your-id!your-token"
proxmox_token_secret = "your-secret"
```

Create `infrastructure/machines.auto.tfvars`:
```hcl
pvebeast_url           = "https://192.168.1.2:8006/api2/json"
proxmox_node_1         = "proxmox"
proxmox_node_2         = "proxmox2"
proxmox_node_1_storage = "local"
proxmox_node_2_storage = "local-lvm"
proxmox_node_1_bridge  = "vmbr0"
proxmox_node_2_bridge  = "vmbr0"

cluster_name = "homelab"
cluster_vip  = "192.168.1.100"

# 3 control plane: 2 on node_1, 1 on node_2
control_plane_count = 3

# 4 workers: 2 on node_1, 2 on node_2
worker_count = 4
```

### 3. Deploy

Run the automated deployment:
```bash
./scripts/deploy-cluster.sh
```

Or manually:
```bash
# Provision infrastructure
cd infrastructure
tofu init
tofu apply

# Configure Talos
cd ../ansible
ansible-playbook playbooks/talos-bootstrap.yml -i inventory/hosts.yml
```

### 4. Verify

```bash
kubectl get nodes -o wide
kubectl get pods -A
talosctl health
```

## Network Architecture

### IP Allocation

- **Control Plane**: `192.168.1.50-52` (3 nodes)
- **Workers**: `192.168.1.60-63` (4 nodes)
- **Cluster VIP**: `192.168.1.100`
- **Gateway**: `192.168.1.1`

### Node Distribution

**High Availability across 2 Proxmox nodes:**

| VM | Proxmox Node | IP | Role |
|----|--------------|-----|------|
| talos-control-1 | node_1 | 192.168.1.50 | Control Plane |
| talos-control-2 | node_1 | 192.168.1.51 | Control Plane |
| talos-control-3 | node_2 | 192.168.1.52 | Control Plane |
| talos-worker-1 | node_1 | 192.168.1.60 | Worker |
| talos-worker-2 | node_2 | 192.168.1.61 | Worker |
| talos-worker-3 | node_2 | 192.168.1.62 | Worker |

### Network Flow

1. VMs boot from Talos ISO
2. Obtain temporary DHCP IP from network
3. Ansible applies Talos config with static IP
4. Talos reconfigures network interface with static IP
5. Static IPs are permanent (no DHCP dependency)

## Configuration

### Scaling

Adjust node counts in `machines.auto.tfvars`:
```hcl
control_plane_count = 5  # Must be odd number
worker_count        = 10 # At least 3 for quorm
```

### Resources

Customize VM resources:
```hcl
control_plane_cores  = 4
control_plane_memory = 8192
worker_cores         = 8
worker_memory        = 16384
```

## Maintenance

### Destroy Cluster

```bash
cd infrastructure
tofu destroy
```

### Update Talos

1. Download new ISO to Proxmox
2. Update `talos_iso` variable
3. Redeploy

### Backup Secrets

```bash
# Backup Talos secrets
cp ansible/secrets/secrets.yaml ~/backups/

# Backup kubeconfig
cp ~/.kube/config ~/backups/
```
