# Talos Ansible Configuration

This Ansible playbook configures Talos Linux nodes with static IPs and bootstraps the Kubernetes cluster.

## Prerequisites

- `talosctl` installed
- `kubectl` installed
- VMs provisioned via Terraform
- Ansible inventory generated by Terraform

## Usage

### Bootstrap Cluster

```bash
# Navigate to ansible directory
cd ansible

# Run the bootstrap playbook
ansible-playbook playbooks/talos-bootstrap.yml -i inventory/hosts.yml
```

### What the Playbook Does

1. **Generates Talos secrets** - Creates encryption keys for the cluster
2. **Creates machine configs** - Generates configs with static IPs embedded
3. **Waits for VMs to boot** - Waits for Talos API (port 50000) to be available
4. **Applies configurations** - Sends configs to each node via DHCP IPs
5. **Waits for network reconfiguration** - Nodes switch to static IPs
6. **Bootstraps Kubernetes** - Initializes the cluster on first control plane node
7. **Merges kubeconfig** - Adds cluster to your `~/.kube/config`

## Generated Files

```
ansible/
├── secrets/
│   └── secrets.yaml          # Cluster secrets (gitignored)
├── generated/
│   ├── controlplane.yaml     # Control plane machine config
│   ├── worker.yaml           # Worker machine config
│   └── talosconfig           # Talosctl client config
├── patches/
│   ├── controlplane.yaml     # Control plane network patch
│   └── worker.yaml           # Worker network patch
└── inventory/
    └── hosts.yml             # Generated by Terraform
```

## Post-Bootstrap

After successful bootstrap:

```bash
# Check cluster health
talosctl health --nodes 192.168.1.50,192.168.1.51,192.168.1.52

# Get nodes
kubectl get nodes -o wide

# Get all pods
kubectl get pods -A
```

## Troubleshooting

### VMs not responding on port 50000

Check Proxmox console to ensure VMs booted from ISO:
```bash
# Check VM status in Proxmox
ssh root@proxmox-host
qm status 501
```

### Static IP not applying

Check Talos logs:
```bash
talosctl dmesg --nodes 192.168.1.50
talosctl logs --nodes 192.168.1.50 controller-runtime
```

### Bootstrap fails

Verify all control plane nodes are healthy:
```bash
talosctl health --nodes 192.168.1.50,192.168.1.51,192.168.1.52
```

## Network Flow

1. **Initial Boot**: VM gets DHCP IP (matches UniFi reservation)
   - Control-1: `192.168.1.50`
   - Control-2: `192.168.1.51`
   - Control-3: `192.168.1.52`

2. **After Config Applied**: Talos sets static IP (same as DHCP)
   - No IP change occurs
   - UniFi reservation provides DNS and backup DHCP

3. **Cluster VIP**: `192.168.1.100` (shared across control plane)
   - API accessible at `https://192.168.1.100:6443`

## Re-bootstrap

To destroy and recreate:

```bash
# Destroy infrastructure
cd ../infrastructure
tofu destroy

# Recreate
tofu apply

# Re-run Ansible
cd ../ansible
ansible-playbook playbooks/talos-bootstrap.yml -i inventory/hosts.yml
```
